# smoke-counter-26041844 — Ürün Gereksinimleri Dokümanı

## 1. Genel Bakış

smoke-counter, kullanıcının sayısal bir değeri artırma, azaltma ve sıfırlama işlemlerini yapabildiği minimal bir sayaç uygulamasıdır. Sayaç değeri tarayıcıda localStorage üzerinde kalıcı olarak saklanır, böylece sayfa kapatılıp yeniden açıldığında son değer korunur. Uygulama React 18 + Vite + TypeScript ile geliştirilmiş tek sayfalık bir web uygulamasıdır. Hedef kitle: genel kullanıcılar, geliştirici smoke testi yapan ekipler. Türkçe arayüz sunulur.

## 2. Hedefler

- Kullanıcı sayısal bir değeri 1 artırabilir (+ butonu)
- Kullanıcı sayısal bir değeri 1 azaltabilir (- butonu)
- Kullanıcı değeri sıfırlayabilir (reset butonu)
- Sayaç değeri tarayıcıda localStorage ile kalıcı olarak saklanır
- Sayfa yenilendiğinde veya tarayıcı kapatılıp açıldığında son değer korunur
- Uygulama ilk yüklemede 2 saniyeden hızlı açılır
- Mobil ve masaüstü tarayıcılarda düzgün çalışır
- Klavye ile tüm işlemler yapılabilir

## 3. Tech Stack Detayı

- **Framework:** React 18.3 (functional components, hooks)
- **Build:** Vite 5.x — hızlı geliştirme sunucusu ve üretim build aracı
- **Styling:** CSS Modules — scoped stil, bileşen başına ayrı .module.css dosyası
- **State:** React useState hook — basit state yönetimi yeterli
- **Storage:** localStorage API — window.localStorage ile değer saklama, JSON serialization
- **Routing:** Yok (tek sayfa, SPA)
- **Language:** TypeScript 5.x — tip güvenliği
- **Testing:** Vitest — birim testler
- **Deployment:** Basit static serve (npx serve dist) veya Vercel preview

## 4. Fonksiyonel Gereksinimler

### 4.1 Sayaç Değeri Artırma
- "+" butonuna tıklandığında sayaç değeri 1 artar
- Her artırma işleminde değer localStorage'a kaydedilir
- Artırma işlemi anında UI'da yansır (reactive update)
- Negatif değerlere izin verilir (sınır yok)
- Hata durumu yok, her zaman başarılı

### 4.2 Sayaç Değeri Azaltma
- "-" butonuna tıklandığında sayaç değeri 1 azalır
- Her azaltma işleminde değer localStorage'a kaydedilir
- Negatif değerlere izin verilir
- Hata durumu yok, her zaman başarılı

### 4.3 Sıfırlama
- "Sıfırla" butonuna tıklandığında sayaç değeri 0 olur
- Değer localStorage'a kaydedilir
- Kullanıcı onay gerektirmez, doğrudan sıfırlanır

### 4.4 Kalıcı Depolama (localStorage)
- Uygulama ilk açıldığında localStorage'dan "counter" anahtarında kayıtlı değer okunur
- Kayıtlı değer yoksa veya geçersiz ise başlangıç değeri 0 kabul edilir
- Her artırma, azaltma veya sıfırlama işleminden sonra değer localStorage'a yazılır
- Saklanan veri formatı: JSON string olarak saklanan number

### 4.5 Arayüz Etketleri (Türkçe)
- Başlık: "Smoke Sayacı"
- Artırma butonu: "Arttır"
- Azaltma butonu: "Azalt"
- Sıfırlama butonu: "Sıfırla"
- Mevcut değer: "Değer" etiketi ile sayısal gösterim
- Boş değer durumu (NaN/Geçersiz): "Değer okunamadı — 0 kullanılıyor"

## 5. Veri Modeli

### CounterState (localStorage)
```
{
  value: number  // Sayaç değeri, integer veya 0
}
```
- Saklanan anahtar: "counter"
- Değer tipi: JSON.parse ile number'a dönüştürülür
- Hatalı veri durumunda (NaN, null, undefined): 0 varsayılır

### In-Memory State (React useState)
```
{
  count: number  // Mevcut sayaç değeri
}
```

## 7. Non-Functional Requirements

### 7.1 Performans
- İlk yükleme (production build): < 1.5 saniye (code splitting, lazy yok — tek sayfa)
- Vite geliştirme sunucusu: < 500ms hot reload
- Bundle size hedefi: < 100KB gzipped (JS)
- Sayaç güncellemesi: < 16ms (60fps UI güncellemesi)

### 7.2 Erişilebilirlik (WCAG 2.1 AA)
- Klavye navigasyonu: Tab ile butonlara erişim, Enter ile tetikleme
- Screen reader: ARIA live region ile sayaç değeri duyurulması
- Kontrast oranı: Primary blue (#2563eb) on white >= 4.5:1 ✓
- Focus state: 2px outline offset, primary color focus ring
- Touch hedefleri: >= 44x44 px (butonlar)
- Reduced motion: respects prefers-reduced-motion

### 7.3 Tarayıcı Desteği
- Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- iOS Safari 14+, Android Chrome 90+
- localStorage gerektirir — private/incognito modda çalışır (sessionStorage fallback opsiyonel)

### 7.4 Güvenlik
- XSS koruması: value display'de string interpolation değil, React JSX text rendering
- localStorage verisi kullanıcı girdisi değil, salt sayısal — güvenli
